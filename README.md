# Diploma Multi-Agent

A Python project for my diploma thesis exploring multi-agent systems and their applications.

## Overview

This repository contains the implementation and research work for a diploma thesis project focused on multi-agent systems. The project is written entirely in Python and provides a framework for developing, simulating, and analyzing multi-agent architectures.

## Features

- Multi-agent system framework
- Agent communication and coordination
- Simulation and testing utilities
- Analysis tools for agent behavior

## Requirements

- Python 3.7 or higher

## Installation

1. Clone the repository:
```bash
git clone https://github.com/4ndr-34/diploma-multi-agent.git
cd diploma-multi-agent
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```
